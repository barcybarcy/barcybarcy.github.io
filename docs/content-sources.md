## 프로젝트 이미지

아래 10장은 사용자가 직접 제공한 이미지입니다. 프로젝트 분류는 사용자의 지정과 해당 이미지의 프로젝트 내용을 기준으로 하며, 각 갤러리 안에서 아래 순서를 유지합니다. BARO와 ENS CFD 연구의 수상 사진은 각 갤러리 마지막에 추가합니다. 파일은 `public/images/projects/`에 원본 그대로 복사하고, 크기와 화면 배치는 CSS로 조정합니다. 이미지 자체의 디자인은 수정하지 않습니다.

`src/projectImages.ts`에서 이미지 매핑, 한·영 캡션·대체텍스트와 썸네일 표시 방식을 관리합니다. 사진 자산 10장과 위 순서는 유지하며, DRAWN은 기존의 SVG 개념 커버를 사용합니다.

경험 본문의 사진은 전체 폭을 사용하고 역할·기술 정보는 아래 행에 표시합니다. `src/components/ExperienceGallery.tsx`의 `expanded`와 `onToggle`을 경험 제목·펼치기 버튼과 연결합니다. 사진이 여러 장인 경험을 펼치면 모든 사진을 원본 비율로 표시하며, `ExperienceGallery.css`에서 넓은 화면 2열·760px 이하 1열로 배치합니다. 갤러리 내부의 펼치기·접기 버튼을 사용한 경우에만 변경 후 사진 시작 위치로 스크롤합니다. 외부의 경험 제목 조작, 초기 렌더링, 언어 변경에는 이 스크롤을 적용하지 않습니다.

대표 사진이나 펼쳐진 사진을 누르면 어두운 전체 화면 뷰어가 열립니다. 사진 표시 공간을 확보하기 위해 하단 썸네일은 열 때마다 접힌 상태이며, 상단 `사진 목록 / Image thumbnails` 아이콘 버튼으로 열고 닫습니다. 이전·다음 버튼, 좌우 방향키와 모바일 좌우 스와이프로 사진을 탐색할 수 있고 원본 이미지 링크도 제공합니다. 닫기 버튼이나 Esc로 뷰어를 닫으면 사진을 열었던 버튼으로 포커스를 복원합니다. 이 배치와 조작 변경은 이미지 원본을 수정하지 않습니다.

## 편집 원칙

- 화면 순서는 소개 → 기술과 도구 → 대표 경험 → 수상 경력 → Contact입니다. 교육 섹션은 표시하지 않으며 Google Cloud 자격과 운전면허는 기술과 도구 섹션의 작은 행에 유지합니다.
- `수상 경력 / Awards`는 경험 5개 뒤, Contact 직전의 독립 섹션입니다. ML Empowerment, QI 해커톤, BARO 캡스톤, ENS CFD RISE 수상의 4개 항목을 표시합니다. RISE 수상의 프로젝트 맥락은 ENS CFD 기반 의료 창업 아이디어로 명시합니다.
- 연락처는 `Contact` 제목과 이메일·GitHub·LinkedIn 아이콘 버튼으로 구성하며 별도의 인사말이나 기회 제안 문구를 표시하지 않습니다.
- 기술·도구의 한·영 이름 13개는 `src/data.ts`의 `getSkills()`에서 관리합니다. `src/components/SkillsSection.tsx`와 `SkillsSection.css`에서 번호나 분야별 카드 없이 아이콘과 이름이 화면 너비에 맞춰 줄바꿈되는 하나의 목록으로 표시합니다. 경험별 구현 기술은 각 경험의 설명에 별도로 유지합니다.
- 사업 매출은 최신 사용자 설명의 1억 8천만 원(KRW 180 million)을 사용합니다. 기존 이력서의 달러 환산 매출을 함께 표기하거나, 매출 기준·기간을 추가로 해석하지 않습니다.
- 주요 경험은 온라인 쇼핑몰 사업 → BARO → PARAGON → ENS CFD 연구 → DRAWN 순서입니다. RealDoor LA, SIC Assembler와 Spring Boot Blog는 현재 메인 콘텐츠에서 제외했습니다.
- PARAGON과 BARO에는 확인되지 않은 GitHub 주소를 만들어 넣지 않았습니다. DRAWN에도 확인된 저장소나 서비스 링크가 없습니다.
- DRAWN의 `Drone Design`과 `Performance Inference`는 분야를 설명하는 태그이며 구현 기술을 뜻하지 않습니다. 검증되지 않은 비행 시간·거리·정확도는 기재하지 않습니다.
- 논문 게재·발표 완료를 주장하지 않습니다. 사이트에는 연구 활동만 기재했습니다.
- 프로젝트 갤러리는 사용자가 직접 제공한 현장 사진·화면·해석 이미지를 사용합니다. 이미지 캡션은 해당 프로젝트와 화면의 내용을 설명하며, 이미지에서 확인하지 않은 성능 수치를 추가하지 않습니다.
- DRAWN에 사용하는 `src/components/ExperienceCover.tsx`의 커버는 독립적으로 제작한 개념 일러스트이며 실제 제품 화면이나 비행 성능의 증거가 아닙니다.
- 카피의 관점·배운 점은 확인된 이력을 바탕으로 작성한 소개 문구입니다. 사용자의 정확한 표현에 맞춰 수정할 수 있습니다.
