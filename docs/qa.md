- 교육 섹션과 관련 번역 항목을 제거했습니다. 본문의 섹션은 `home`, `about`, `skills`, `projects`, `awards`, `contact`입니다.
- 기술·도구 13개와 자격·면허 2개에 텍스트와 아이콘이 함께 표시됩니다. 데스크톱 1265×850에서 아이콘과 이름의 배치를 확인했습니다.
- 제공된 원본 10장을 사업 2장, BARO 5장, PARAGON 1장, ENS CFD 2장으로 연결했습니다. DRAWN은 기존 개념 그림을 유지합니다.
- BARO 사진은 구상 → 시연 → 제조 현장 방문 → 대시보드 → 캡스톤 수상 순서입니다. ENS CFD는 유동 해석 → RISE 수상 순서입니다. 추가된 두 수상 사진의 썸네일 선택, 실제 로드, 확대 화면을 확인했습니다.

- 사진 선택·이동·전체 화면 보기는 경험 상세를 열지 않습니다. 사진 모아보기와 제목 버튼은 사진 목록과 경험 상세를 함께 펼칩니다.
- PARAGON과 ENS CFD의 확대 이미지가 정상 로드됩니다. PARAGON의 한 장짜리 갤러리에는 이동 버튼이 표시되지 않으며, ENS CFD에는 수상 사진 추가 후 두 장을 선택할 수 있습니다.
- KOR / ENG 전환 시 선택한 사진을 유지하면서 캡션과 버튼 이름을 번역합니다. 320×740 영문 화면에서 가로 넘침과 남은 한국어가 없으며, 확대 사진·닫기·이동 버튼을 사용할 수 있습니다.
