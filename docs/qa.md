- 모바일 메뉴 열기·닫기와 프로젝트 섹션 이동, 이동 후 메뉴 자동 닫힘.

- 상세 창 표시 중 페이지에 중복 ID 없음. SVG 정의에 인스턴스별 ID 사용.

- 확인 시점의 브라우저 오류·경고 로그 없음.
